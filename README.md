# 🟨 JavaScript - Práticas e Exercícios

Este repositório reúne atividades desenvolvidas em sala de aula com o objetivo de **aprimorar conhecimentos em JavaScript**.

Os exercícios focam na prática de conceitos fundamentais da linguagem, aplicados em pequenos projetos e desafios.
